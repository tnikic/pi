# Closing Summary Format

Written when the frontier is empty and the map is ready to close. This is the handoff artifact — to-spec consumes it, the human reads it.

```markdown
## Route found

<Narrative synthesis of the key decisions — the route from destination to
clarity. Not a list, but a coherent story: "We determined that X, which
meant Y, and ultimately landed on Z." 2–4 paragraphs.>

## Key decisions

- [Decision ticket name](link) — one-line gist
- ...

## Residual fog

<Items that weren't sharp enough to ticket. Each either links to a follow-up
map, or is noted as unresolved with a one-line description.>

## Out of scope

<What was ruled beyond this effort, with rationale for each. Links to any
follow-up maps.>
```
